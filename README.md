# VAA-Website
Official website for VAA Resources Pty Ltd

Static HTML website deployed from `main` to GitHub Pages at https://www.vaaresources.com/.

Run the local checks with `node --test tests/site-checks.cjs` (no dependencies).
See [measurement notes](docs/measurement.md) for Analytics event meanings and reporting follow-up.

The September 2026 site photographs are web-size derivatives without embedded GPS/EXIF metadata.
Project updates must distinguish proposed activities and lodged applications from approvals or operating results.
