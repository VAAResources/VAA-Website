# VAA-Website
Official website for VAA Resources Pty Ltd

Static HTML website deployed from `main` to GitHub Pages at https://www.vaaresources.com/.

Run the local checks with `node --test tests/site-checks.cjs` (no dependencies).
See [measurement notes](docs/measurement.md) for Analytics event meanings and reporting follow-up.

The September 2026 site photographs are web-size derivatives without embedded GPS/EXIF metadata.
Project updates must distinguish proposed activities and lodged applications from approvals or operating results.

Public approval wording is intentionally general: approvals and preparation are
progressing. Do not publish application identifiers, assessment timetables or
regulator-by-regulator progress without a new content decision.

FRABEN has a dedicated page at `/technology/fraben.html`; the earlier project-page
`#fraben` anchor is retained for shared links. The existing Holleton update URL is
also retained, with its public text and metadata updated to a general progress
summary. Preserve original publication dates and update modification dates only
when content materially changes.

The homepage hero has 800, 1600 and 2400-pixel variants with matched image/preload
source sets. The smaller versions retain the original photograph and composition;
no objects have been added or removed.
